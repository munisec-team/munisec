# Script backups JSBach

✅ Tarea realizada: Realizado
👤 Persona: Jose Luis Oliver Herranz
📅 Fecha: 28 de abril de 2026
📝 Descripción / Bitácora: A fecha 28 de abril se ha implementado un parámetro --backup y --restore que permite hacer un backup de todos los ficheros de configuración importantes de JSBach y restaurarlos en un equipo con JSBach recién instalado. Esto nos facilitará el proceso en caso de que vuelva a ocurrir una “tormenta”.
