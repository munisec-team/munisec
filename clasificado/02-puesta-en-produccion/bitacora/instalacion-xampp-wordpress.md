# Instalación xampp y Worpress

👤 Persona: kike
📅 Fecha: 26 de marzo de 2026

Se procede a la instalación de XAMPP como entorno de servidor local, seguida de la instalación de WordPress. Durante el proceso, se crea una base de datos en phpMyAdmin y se configura WordPress para que quede correctamente vinculado a dicha base de datos, dejando el entorno listo para su desarrollo.
